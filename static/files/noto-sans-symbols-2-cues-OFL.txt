LeapView Chart Cues is a subsetted derivative of the Noto Sans Symbols 2
5.3.0 and Noto Sans Symbols 5.3.0 web fonts published by Fontsource. The
subset contains only U+2191 U+2193 U+25A0 U+25B2 U+25BC U+25C6 U+25CF U+26A0.
The source archives are pinned by the @fontsource packages in package.json;
the source archive SHA-256 values are:

  fontsource-noto-sans-symbols-2-5.3.0.tgz
  dd714f47e1ba768274c25d14ac95610ca32e416d70c5455cd11d8995042a4552
  fontsource-noto-sans-symbols-5.3.0.tgz
  f38047dcf42fcf90e7e9fcd3cb07f6900186d30137b173aa6f63f17d86b30db9

The generated subset SHA-256 is:
  814efd1ab221bc83136fd9c3e485dc21863737e422e733abe43086235b44c03c

Reproduction (verified with Python 3.13.5, fontTools 4.65.0, and Brotli
1.2.0; set PYTHONPATH to the fontTools environment):
  PYTHONPATH=/tmp/fai-fonttools SOURCE_DATE_EPOCH=1789101809 python3 -m fontTools.merge /tmp/noto-sans-symbols-2-symbols.woff2 /tmp/noto-sans-symbols-symbols.woff2 --output-file=/tmp/leapview-chart-cues.ttf
  PYTHONPATH=/tmp/fai-fonttools SOURCE_DATE_EPOCH=1789101809 python3 - /tmp/leapview-chart-cues.ttf /tmp/leapview-chart-cues-fixed.ttf <<'PY'
  import sys
  from fontTools.ttLib import TTFont
  source, target = sys.argv[1:]
  font = TTFont(source, recalcTimestamp=False)
  font['head'].modified = font['head'].created + 1
  font.save(target, reorderTables=False)
  PY
  PYTHONPATH=/tmp/fai-fonttools python3 -m fontTools.subset /tmp/leapview-chart-cues-fixed.ttf --unicodes=U+25A0,U+25B2,U+25BC,U+25C6,U+25CF,U+2191,U+2193,U+26A0 --flavor=woff2 --output-file=noto-sans-symbols-2-cues-400-normal.woff2

The timestamp normalization is required for byte-identical output; the
un-normalized merge otherwise differs only in the OpenType head timestamps.

The first input is package/files/noto-sans-symbols-2-symbols-400-normal.woff2
from @fontsource/noto-sans-symbols-2@5.3.0. The second is
package/files/noto-sans-symbols-symbols-400-normal.woff2 from
@fontsource/noto-sans-symbols@5.3.0; the Noto Sans Symbols 2 package's
published subset does not contain U+2191/U+2193, so this same-family Noto
source supplies those two arrow outlines before the final restricted subset.
