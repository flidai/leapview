now implements exact publication-to-approval-to-activation binding for the
explicit already-ACTIVE, unchanged-protected-contract profile. First activation,
restore, changed protected contracts and protected rollback remain fail closed;
DataPolicy removal is not included. The bounded implementation does not change
this matrix's counts.

defines positively exercised building blocks, excluded production capabilities,
control ownership, and the evidence FAI-649 must consume. It does not enable
production or narrow the normative requirements below. Counts remain
**55 PASS / 45 PARTIAL / 2 FAIL**; STR-08 and ENF-06 remain cutover-owned.

4, STR 12, ATT 12, VAL 11, GRT 10, FLT 10, PLN 9, ENF 11, CMP 6, LIF 8,

for the full wording of the row. `PARTIAL` identifies an implemented slice
whose full profile path is not qualified. `FAIL` identifies a missing or
contradictory implementation. `NOT APPLICABLE` is reserved for a requirement
outside this profile.
