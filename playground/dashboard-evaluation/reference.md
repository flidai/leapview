# Fixed trial reference
Canonical envelope apiVersion leapview.dev/v1, kind Dashboard, metadata id dashboard:evaluation and name evaluation. spec semanticModel sales; filters, visuals and pages are lists.
Visual definitions carry required id, type, query and presentation. Query type aggregate requires ordered dimensions and metrics. A dimension can be a semantic name string or an object {dimension, grain, alias}; sort is a list of {field, direction: asc|desc}. Sort fields reference result names, including aliases. limit is a positive integer.
Presentation type is cartesian for area and kpi for kpi. KPI displayUnits auto is supported. Aggregate no-dimension selection is dimensions: []; metrics: [revenue].
Semantic catalog: purchase_date is a Date dimension; legal grains day, week, month. revenue is a sum metric with currency formatting. order_count is a count-distinct metric. Model sales is governed; SQL/expressions are forbidden.
Layout defaults when omitted: columns12,rowHeight48,gap16,padding16. Explicit layout uses fields columns,rowHeight,gap,padding. Page id/title/components required. Visual component has id,type: visual,visual: <visual id>,placement {column,row,columnSpan,rowSpan}. Coordinates and spans >=1; no overlap; column+columnSpan-1 <=12.
Includes are root spec.includes.visuals/pages path lists. Root still has visuals: [] and pages: []. A visuals fragment is an object with visuals list; a pages fragment is an object with pages list. Paths relative to root. Composition unions definitions by ID, rejects duplicate IDs, and concatenates pages in include order; no overriding or deep merging.
Author only the requested fields. No arbitrary tags, custom renderer settings or hidden defaults. The source is validated after submission; these references supply identical authoring semantics to every trial.
