# Exploratory legal-v1 pilot — preregistered before trial dispatch
Prepared 2026-10-08; supersedes no90-run plan. This9-run discovery pilot qualifies existing legal forms before unimplemented canonical simplification/layout candidates can be compared. It cannot estimate reliable success rates or select A/B/C.
Design: explicit defaults, omitted equivalent defaults, confined fragments × create, change grain/alias/sort, edit reused visual after reorder. One fresh independent agent submission per cell;9 runs. Same inherited model/config, fixed reference, task wording, shell access and no compiler feedback; candidate-specific representation constraint only. No repairs.
Root dispatches independent agents, records order/elapsed time and final submissions, then freezes hashes of first attempts before grading. No other trial output or oracle is accessible under the permitted prompt scope. Agents may see filenames only within their supplied directory.
Primary pass: real strict Go compilation plus normalized expanded document equals the frozen task oracle, treating visual-definition order as identity-independent and omitted layout as12/48/16/16. Page/component/query order remains meaningful. Representations must retain assigned form. Metadata, other visuals, shared references, filter state and layout preserved.
Report schema/parse acceptance, compiler acceptance, exact intended binding result, source bytes and changed files separately; preserve failures and counts. Compiler acceptance alone cannot establish intended chart meaning. No rendered-data or end-to-end query-execution claim is made by a document/compiled-binding oracle.
All known bounds and starter corrections apply to every form. No syntax changes or new authoring tools are treatments. Absent token measurements are reported unavailable. No percentage improvement claim from one trial per cell.
Exact expected documents are in oracle/ for graders, intentionally excluded from trial reference. This preregistration and oracle hashes must be captured before dispatch.
